VIDEO: {title}

Create quiz questions, flashcards, and practice scenarios from the extracted language content.
Focus on practical language skills the viewer can use immediately.

Quiz: Test comprehension of vocabulary, grammar rules, and usage.
- Each question has 4 options with exactly 1 correct answer (correctIndex is 0-based)
- Include translation, pronunciation, and grammar questions
- Reference specific phrases and rules from the lesson
- Mix question types: "What does X mean?", "Which is correct?", "When would you say X?"

Flashcards: Create vocabulary and phrase review cards.
- Front: target language word/phrase
- Back: translation + pronunciation + usage context
- Include all vocabulary items as flashcards
- Add key phrases as additional flashcards
- Order from basic to advanced

Scenarios: Present real-world situations where the learner uses the language.
- Each scenario has 3-4 options with exactly 1 correct
- Set scenes in realistic contexts (restaurant, airport, meeting)
- Test ability to choose the right phrase for the situation
- Explanations should teach cultural context and politeness levels
</instructions>
