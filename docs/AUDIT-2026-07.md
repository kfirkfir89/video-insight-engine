## What the re-audit verified as genuinely fixed

The baseline's central diagnosis was **"built but not enforced."** The re-audit confirmed
the cure took, with file-level evidence for every claim:

- **CI is now a real gate**: 11-job matrix (typecheck incl. web `tsc -b`, ruff+pyright,
  every suite incl. previously-uncovered admin×2 + llm-common, docker-build, design-guards)
  plus e2e smoke (Mongo-seeded, zero LLM spend) and eval workflows (PR dry-run gate,
  retrieval recall/MRR floors with anti-silent-skip assertions, weekly live golden eval).
- **Auth follows its own docs**: dual-secret JWT with `type` claims and adversarial tests;
  real per-user rate limiting (two-users-same-IP proof); prod boot refuses placeholder
  secrets; timing-safe compares; Paddle replay rejection; WS auth out of the query string.
- **Contracts machine-checked**: TS↔Pydantic parity tests that parse `vie-response.ts`
  itself; PIPELINE_VERSION single-sourced from `packages/shared/src/config/pipeline-version.json`
  and stamped/version-checked on Mongo docs; SSE events Pydantic-validated at emission;
  29-schema Zod gate at the web tab boundary with prod-visible drift counters
  (`window.__vieTelemetry`); caps/requirements single-sourced from domains.json.
- **LLM quality measured and gated**: committed baselines (retrieval recall@3 1.0 /
  MRR 0.865 with floors; faithfulness judge 20/20 on labeled claims with claim-localized
  BM25-style context instead of the old head-window); golden-eval dry-run CI gate;
  degraded runs surfaced doc→SSE→UI→admin.
- **Recovery story exists**: backup/restore scripts with an executed drill; prod compose
  rewritten (11 services, `${VAR:?required}` ×13, zero published datastores, non-root pinned
  images, lockfiles); Sentry initialized in all five services + web with PII scrubbing;
  `llm_usage` TTL removed (verified live); alert delivery proven.
- **Frontend quality automation from zero**: visual-regression baselines ×3 themes,
  React Flow edge-render browser smoke (RF #008 class), axe = 0 violations on 4 pages,
  focus-restore locked by tests, aria-live on quiz/checklist, accent-only CI guard.
- **Process machinery**: tested PreToolUse git-safety guard (mechanically blocks the
  2026-05-28 stash scenario), husky pre-commit chain, fixed session-snapshot hook, docs
  reconciled against code (14 domains, SECURITY/ERROR-HANDLING/IDEMPOTENCY), stale
  CODE-REVIEW-FIXES dispositioned and archived, MEMORY under load budget.
